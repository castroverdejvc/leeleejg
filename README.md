# LeeLEEJG

App para aprender a leer: una historia al día con fotos, preguntas, un pequeño reto de números y cromos.

**Instalar en una tablet o un móvil:** abre esta app en el navegador (Chrome en Android, Safari en iPad) y añádela a la pantalla de inicio. La primera vez guarda el programa y las fotos; después funciona sin internet.

Los datos de cada niño (lecturas, grabaciones, fotos) se guardan solo en el aparato. Para juntarlos con el ordenador se usa «Enviar a OneDrive» en Familia › Datos y copias.

Este repositorio solo contiene el programa; se genera con `codigo/preparar_tablet.py`.
